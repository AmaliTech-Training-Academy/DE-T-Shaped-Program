# T-Shaped Data Engineering Programme — Skill Details

---

## SK-01 — Python Data Engineering Practitioner

- Structure Python projects following professional conventions
- Ingest data from multiple formats: CSV, JSON, XML, REST APIs, and fixed-width files
- Clean and deduplicate raw datasets programmatically
- Validate data quality using rule-based checks
- Build and deliver end-to-end Python data pipelines
- Produce data visualisations and summary reports

---

## SK-02 — SQL and Data Modeling Specialist

- Write complex analytical SQL using window functions, CTEs, and recursive queries
- Design star schemas with fact and dimension tables
- Implement Slowly Changing Dimensions (SCDs) for historical data tracking
- Optimise fact tables and queries using indexes and materialised views
- Build and maintain a dimensional data warehouse

---

## SK-03 — Batch ETL and Orchestration Engineer

- Process large datasets using PySpark (understanding jobs, stages, and tasks)
- Author and schedule Apache Airflow DAGs with retry and failure handling
- Build dbt transformation models with built-in tests and documentation
- Design idempotent, incremental ETL pipelines
- Monitor and troubleshoot distributed batch processing workflows

---

## SK-04 — AWS Cloud Data Engineer

- Design a three-zone S3 data lake (raw / processed / curated)
- Apply IAM least-privilege policies for data access security
- Build serverless ETL jobs using AWS Glue
- Query data cost-efficiently with Amazon Athena using partitioning strategies
- Model and load data into Amazon Redshift
- Codify cloud infrastructure using AWS CloudFormation

---

## SK-05 — Real-Time Streaming Engineer

- Design Kafka topics with appropriate partitioning and replication strategies
- Produce and consume events with exactly-once delivery guarantees
- Ingest streaming data using AWS Kinesis Firehose
- Build event-driven processors with AWS Lambda
- Apply windowed and stateful stream aggregations
- Handle late-arriving and out-of-order events in production pipelines

---

## SK-06 — Power BI Analytics Practitioner

- Model star schemas optimised for Power BI performance
- Author DAX measures for time intelligence and complex filter-context calculations
- Design interactive reports and executive dashboards
- Implement row-level security (RLS) to enforce data access policies
- Manage Power BI workspaces and deployment pipelines

---

## SK-07 — Microsoft Fabric Data Engineer

- Provision and configure Microsoft Fabric workspaces
- Architect OneLake lakehouses using the medallion pattern (Bronze / Silver / Gold)
- Author Spark notebooks for multi-layer data transformation
- Build Fabric data pipelines for orchestrated ingestion and processing
- Virtualise external data sources using OneLake shortcuts
- Expose curated data via the SQL Analytics Endpoint

---

## SK-08 — Data Lakehouse Architect

- Design medallion architectures for large-scale lakehouse platforms
- Implement ACID-compliant Delta Lake tables with time travel and schema evolution
- Apply file optimisation techniques: OPTIMIZE, Z-ORDER, and VACUUM
- Compare and select between Delta Lake and Apache Iceberg for given workloads
- Architect production lakehouses that support both batch and streaming consumers

---

## SK-09 — Data Governance & Security Practitioner

- Apply DAMA-DMBOK governance frameworks to data platform design
- Classify data assets and implement cataloguing and metadata management
- Build automated data quality pipelines using Great Expectations
- Track data lineage across pipeline stages
- Enforce access controls, PII masking, and encryption
- Implement compliance controls aligned to GDPR and CCPA requirements

---

## SK-10 — DataOps and CI/CD Engineer

- Design CI/CD pipelines for data pipelines using GitHub Actions
- Write unit and integration tests for ETL and transformation logic
- Containerise data workloads using Docker
- Manage cloud infrastructure as code with Terraform
- Instrument pipelines with monitoring, alerting, and SLA tracking

---

## SK-11 — NoSQL and DynamoDB Specialist

- Model data for NoSQL access patterns using single-table design
- Design DynamoDB partition keys and sort keys for performance at scale
- Build Global Secondary Indexes (GSIs) for alternate query paths
- Implement DynamoDB transactions and conditional writes for data integrity
- Leverage DynamoDB Streams to trigger event-driven downstream pipelines

---

## SK-12 — ML and Data Science for Data Engineers

- Identify ML problem types and their data engineering requirements
- Build feature engineering pipelines for training and inference
- Implement and populate a feature store using Feast
- Design train/test data splits while preventing data leakage
- Support MLOps workflows and model deployment pipelines
- Monitor production data for drift to maintain model reliability
