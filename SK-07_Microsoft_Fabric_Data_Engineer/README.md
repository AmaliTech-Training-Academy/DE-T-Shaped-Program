## What You'll Learn

By the end of this skillset, you will be able to:

- [ ] Navigate Fabric workspaces and understand OneLake and capacity
- [ ] Build Lakehouses with medallion architecture (Bronze/Silver/Gold)
- [ ] Write parameterised Spark notebooks with Delta MERGE, OPTIMIZE and assertions
- [ ] Create data pipelines with error handling, alerts and schedules
- [ ] Use shortcuts to virtualize data across workspaces
- [ ] Query data with T-SQL in the Warehouse and the SQL analytics endpoint
- [ ] Stream events through Eventstreams into an Eventhouse and query them with KQL

## Cost and capacity

- **Everything in SK-07 runs on the free 60-day Fabric trial** (F4 or F64 capacity, up to 1 TB of OneLake storage). You need a work or school account; personal Microsoft accounts can't sign up.
- The trial can't produce a bill, but it can **throttle** if you leave work running. Stop notebook sessions you aren't using, turn pipeline schedules off when a lab ends, and deactivate Eventstreams after Lab_07.
- **Paid F-SKUs bill per hour while running**, busy or idle (an F2 is roughly US$0.36/hour in US regions at the time of writing; check the Azure pricing calculator for your region). Pause the capacity in the Azure portal whenever you stop working.
- [Lab_00](Granular%20Labs/Lab_00_Environment_Setup.md) Section 3.3 and the guided lab's "Before you start" section have the details.

## Fabric Architecture

```
                        ┌─── Power BI Reports (Direct Lake)
                        │
Sources ──→ Lakehouse ──┼─── SQL Analytics Endpoint
   │         (Delta)    │
   │            │       └─── Warehouse (T-SQL)
   │            │
   └── Shortcuts ─────────→ OneLake (unified storage)

Events ──→ Eventstream ──→ Eventhouse (KQL) ──→ Real-Time Dashboard
```

## Badge Criteria

To earn the **Microsoft Fabric Data Engineer** badge:

1. Complete all **Essential** resources
2. Complete the guided Lab
3. Submit a passing Capstone project:
   - Lakehouse with Bronze/Silver/Gold layers
   - Delta table maintenance (OPTIMIZE, VACUUM)
   - Spark notebooks with parameterization
   - Data pipeline with error handling
   - Power BI report using Direct Lake
